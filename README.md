# 九九ファンタジーバトル

九九の習得・定着・弱点発見・再練習を、ファンタジー冒険として一続きにした小学生向けWeb教材です。

## 学習サイクル

`バトル → 誤答記録 → 九九マップ → 仲間と特訓 → 苦手克服 → 再バトル`

- 1〜9の段：のぼり・くだり・ランダム
- 中ボス1：2〜5の段、中ボス2：6〜9の段
- 大ボス：九九全81種類
- 特訓：HP・敵・タイマーなしの10問セット
- 1問単位の履歴、reviewQueue、2回連続正解による克服判定
- バトルはミスした九九で止まり、正解するまで次の九九へ進まない
- 九九マップ、MASTER、冒険Lv、図鑑、Fantasyコレクション
- 学びのバッジ39種＋算数スキルバッジ25種を統合した一覧。獲得済み／未獲得／もう少しで獲得の絞り込み
- 回答数・正答率・最大コンボ・MASTER・ノーミス・苦手克服・81種類の九九への挑戦・図鑑／宝物収集に連動する達成条件
- このアプリでは判定できない図形・分数などの算数スキルは、獲得扱いにせず別教材向けの目標として表示
- 通常／サポート別の記録、ミュート、キーボード対応

## 技術構成

HTML / CSS / Vanilla JavaScript、GitHub Pages、`localStorage`のみで動作します。外部API・APIキー・DB・BGMは使用しません。

設計基盤は[edu-kit](https://github.com/TT-sensei/edu-kit)。ロジック部品は`edu-components`、UI演出は`edu-effects`、効果音は`sounds-recipe-`、報酬は`edu-assets`、キャラクターとモンスターは`navi-character-`の実在する軽量Web素材を参照しています。

## テスト

```bash
node tests.mjs
```

のぼり・くだり、ボス出題範囲、SPECIAL発動条件、誤答キューと間隔再出題、2回連続正解による克服、保存データ復元、バッジの種類数とID重複がないことを確認します。

## ふりがな対応

小学2年生が画面の言葉を読みやすいように、画面内の主要な漢字語句に自動でふりがなを付けます。ホーム画面、冒険マップ、特訓、九九マップ、ナビアン図鑑、コレクション、バッジ名や獲得結果などに対応し、プレイ中に追加表示される文章も監視して処理します。

- 読み方はアプリ内の辞書で管理し、外部のふりがなAPIや通信サービスは使用しません。
- インターネット接続がなくても、アプリ本体と素材が端末に保存されていれば、ふりがな処理自体は動作します。
- 辞書に登録した語句を中心に付ける方式のため、すべての漢字や固有の文章を完全に網羅するものではありません。表示を確認し、読み漏れや読み間違いがあれば辞書を更新してください。
